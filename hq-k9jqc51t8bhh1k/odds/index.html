Losing by construction
Every leg pays the bookmaker's cut and the cuts multiply. This is not an opinion about any particular parlay; it is arithmetic that holds before you pick a single team.

What a parlay actually costs

Each leg priced at −110, a genuine coin flip. Payout is what the book returns; fair payout is what it should return if the bet were free.

LegsPayout True chanceFair payoutYour edge
A four-leg parlay of coin flips returns 83 cents on the dollar. You are not letting it ride — you are paying the fee four times.

The same touchdown pays both legs. This is the only mathematically defensible parlay — but books know it, and same-game parlays carry extra juice precisely to claw it back. Check case by case; never assume.

Retracted

“Strikeouts do most of the work”

Stated from a point estimate with no error bar. With bootstrapped intervals, strikeout rate cannot be distinguished from zero on 4,369 games. Walk rate survives; strikeouts do not.

“The park effect is noise”

Half right, and the wrong half. Ballpark is actively harmful and the interval excludes zero. Likely double-counting: a team's batting stats already contain its home park. Removed.

“Line shopping is the proven edge”

Repeated for four days on the strength of daily snapshots and a proxy. It has no backtest. Reworded to what the evidence supports: shopping reduces the loss.

“The market beats the model”

Said for four days from point estimates, with the validation season pooled into the test season. Split properly with a date-blocked paired bootstrap, every interval crosses zero. Withdrawn.

“Home field contributes nothing”

A [0,0] interval was a bug, not a null. Home teams win 52.86% but score only +0.73% more runs — because they do not bat in the ninth when leading. A run-total model structurally cannot see MLB home field. This is also the mechanism for totals being the only significant losing market.

“Walk rate is a confirmed keeper”

Does not survive Benjamini-Hochberg (p = 0.077). Roughly 50 tests were run across this project with no multiplicity correction at all until now.

“1,100 bets proves a 3-point edge”

Wrong by 57%. It is 1,717 one-sided, 2,180 two-sided at 80% power. For the NFL that is 22 seasons, not eleven.

The −$526 betting simulation

1,138 bets at $100 flat carries a standard error near $3,373 — an interval of roughly −$7,100 to +$6,100 — and used the same games as the log-loss test, so it was never independent evidence. Removed from the scorecard.

Bugs found by testing, not by luck

The model was frozen

Its data stopped on 29 August while it kept answering questions about September games. Nothing was scheduled to refresh it. Now runs daily at 7:47am with a consistency gate that fails loudly if the two files disagree.

Live prices leaking in

Odds captured mid-game look like enormous value on a team already losing 8–1. Five independent gates now catch them; all four real live prices from that day were rejected and both genuine pregame prices kept.

A gate that deleted the point

The disagreement rule threw out a game 4h38m before first pitch — and book disagreement is exactly where shopping value lives. It was protecting the tool by removing its purpose. Disagreement alone can no longer reject anything.
